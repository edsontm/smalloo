# Contributing

Thank you for contributing to this repository.

## Canonical Rules

All contribution rules are defined in AGENTS.md and docs/ai.

Read in this order:
1. AGENTS.md
2. docs/ai/project-overview.md
3. docs/ai/repository-conventions.md
4. docs/ai/development-workflow.md
5. docs/ai/coding-standards.md
6. docs/ai/testing-strategy.md
7. docs/ai/experiment-protocol.md
8. docs/ai/definition-of-done.md

## Pull Requests

- Keep each PR focused on one primary contribution.
- Include tests and documentation updates for behavior changes.
- For research changes, include experiment evidence and reproducibility metadata.
