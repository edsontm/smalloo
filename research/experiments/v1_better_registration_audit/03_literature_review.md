# Literature Review

## Priority sources to review before implementation

- Registration methods used in small object detection from satellite or aerial video
- MMB baseline source and any published registration assumptions
- Strong temporal alignment papers that report downstream detection gains

## Review checklist

For each paper record:

- Citation
- Core idea
- Strengths
- Weaknesses
- Research gaps
- Classification: Incremental / Interesting / High Potential / Game Changer
- Implementation notes
- Combination opportunities
