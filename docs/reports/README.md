# Reports

This directory defines how cross-experiment and periodic reports are documented.

## Expected Contents

- Consolidated run summaries
- Comparative experiment snapshots
- Links to experiment-level artifacts

## Report Requirements

Each report should state:
- date and scope
- experiment slugs
- dataset profile
- execution status by step
- artifact paths
- key caveats and next steps

Follow docs/ai/experiment-protocol.md and docs/ai/definition-of-done.md.
