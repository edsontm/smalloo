# Architecture Decision Records

Use this directory to track architecture decisions as ADRs.

## Rules

- One ADR per decision.
- Keep ADRs immutable after acceptance; supersede with a new ADR when needed.
- Link related PRs, experiments, and migration steps.

## Naming

Use incremental identifiers, for example:
- 0001-runtime-profile-centralization.md
- 0002-experiment-slug-versioning.md

Start from ADR-template.md.
